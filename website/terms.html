1. What HostSpawn does

HostSpawn downloads, installs, starts, updates and backs up game servers on a computer you control, using the official tools and sources of each game (for example Valve's SteamCMD).

You are responsible for the servers you run, the computer they run on, its security and firewall, and for following the law and the rules of each game and platform.

HostSpawn shows these before every server is created and won't continue until you accept them.

4. Accounts and passwords

Use a Steam account you're allowed to use (a separate account just for servers is best). HostSpawn types your Steam password into SteamCMD for you and doesn't store it. HostSpawn account passwords are stored only as salted fingerprints.

HostSpawn is provided "as is". We work hard to keep servers safe and running, but we can't promise they will never stop, lose data or be attacked. Keep backups.
