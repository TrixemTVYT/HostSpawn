# HostSpawn website

A plain static site: `index.html`, `terms.html`, `privacy.html` and `assets/` (style and logo). No build step,
no external fonts or scripts, no cookies or trackers.

## Put it online (when hostspawn.uk is bought)
Recommended: **Cloudflare Pages** (free, HTTPS included).
1. Create a Cloudflare account and add the domain.
2. Pages → Create → upload this `website/` folder (or connect the GitHub repo and set the folder to `website`).
3. Add the custom domain `hostspawn.uk` (and `www`).

Any static host works too (Netlify, GitHub Pages, or a web server).
