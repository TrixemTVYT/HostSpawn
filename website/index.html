Features

Everything a server owner does by hand, done for you

Built by a server owner, for server owners. No command line needed.

01

One-click setup

Pick a game, a server type and a map, press Deploy. HostSpawn downloads the server, writes its settings, picks free ports and starts it, with a live progress screen.

02

Crash and freeze recovery

Checks every server every minute: process, server-list query, RCON and log activity. Restarts crashed or frozen servers, and stops retrying (with an alert) if something is badly wrong.

03

Updates with retries

Game updates through Valve's SteamCMD, retried when Steam has a bad moment. Steam login problems are flagged, never retried until the account locks.

04

Backups on by default

Every server is backed up daily, including databases. You get a warning if a backup is missing or too old. Every wipe and delete makes a backup first.

05

Wipes, restarts, rotation

Rust wipe schedules (monthly, bi-weekly, weekly) around Facepunch's forced wipe. Recommended restart schedules for each game. Map rotation for Arma Reforger.

06

Guided steps

When something needs you (a Steam login, opening firewall ports, installing a database), HostSpawn shows exactly what to do, then checks it worked.

07

Team accounts

Invite your staff as Admins, Moderators (run servers) or Viewers (look only). Every action records who did it.

08

Tools built in

A PBO manager for Arma files, a dependencies checker with install buttons, RCON console for Rust, and live logs.

How it works

From nothing to a live server

Install HostSpawn

A first-run wizard creates your owner account, asks your community name and checks what your machine needs.

Pick a game and type

Choose a game, a server type and a map. Recommended restarts and wipes are filled in for you.

Press Deploy

Watch every step live: download, settings, first start. HostSpawn waits until the server really answers.

Play

Open the ports (HostSpawn shows you how), share the address, and let HostSpawn look after the rest.

Safety first

Built to be trusted with your servers

Your servers, your machine, your data. Safety comes before features.

  • Passwords are never storedOnly a slow, salted fingerprint (scrypt). Sign-in tokens are fingerprinted too.
  • Your Steam password stays yoursTyped straight into Valve's SteamCMD, never saved, logged or shown.
  • Locked against guessingToo many wrong passwords lock the account for a while, doubling each time.
  • Private by defaultThe dashboard only listens on your own machine. Nothing is sent to us.
  • Backups before anything riskyWipes, deletes and updates make a backup first.
  • No surprisesRisky actions ask you to type the action's name. A double-click can't do anything twice.
  • Official sources onlyGames from Steam, Oxide from its official release, mods from their own projects.
  • Roles for your teamModerators can run servers but can't delete, wipe or change settings.

FAQ

Questions

Does HostSpawn host my server?

No. HostSpawn runs your servers on a computer you control: your own PC, a dedicated server or a VPS. That keeps your files and players' data with you.

Which operating systems does it support?

Linux (Ubuntu and Debian) today. Windows 10/11 and Windows Server are on the roadmap. The games themselves only make servers for Windows and Linux, so a Mac can run the app but not host servers.

Do I need a Steam account?

Not for Rust or Arma Reforger. Arma 3's server download needs a Steam account (it doesn't have to own Arma 3). A separate account just for servers is best.

Will it keep my server up if it crashes?

Yes. HostSpawn checks every minute and restarts a crashed or frozen server. If a server keeps failing it stops, tells you, and shows the last log lines, instead of looping forever.

Can I still edit my server's files myself?

Yes. Each server lives in its own folder that you can open and edit. A built-in file browser and config editor are coming next.

Is it free?

HostSpawn is in early access. Pricing hasn't been decided yet; anything you set up during early access stays yours.
